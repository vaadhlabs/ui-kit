# Changelog — @tensorcost/ui-kit

## 1.0.0-alpha.7

- Table: `ResizableTable` subcomponent with pointer-capture drag handles, `localStorage` persistence at `tc_col_widths_<key>`, 48px `MIN_COL_PX` clamp; `Table` forwards new `resizable?: string` prop to it.

## 0.2.0

### Minor Changes

- 9b4c6d4: Initial public release of the TensorCost design system.

  — What's in @tensorcost/tokens —

  Brand tokens (light + dark variants): paper, bgPage, bgSoft, ink scale, border
  scale, semantic colors (blue / cyan / positive / warn / danger / purple),
  radius scale, motion curves, mono font reference. Tone palette for chips and
  callouts (good / bad / warn / info / neutral). Typography scale (fontFamily,
  h4–h6, overline, button). CSS custom-property emitter for non-MUI consumers.
  Raw JSON snapshot for Python / Figma / non-TS consumers.

  — What's in @tensorcost/ui-kit —

  MUI 7 theme factory (createTensorTheme) wiring tokens into a full MUI palette
  - typography + component-override surface. Theme-aware shell (ThemeShellProvider).

  App-chrome components: MetricCard, DataTable, DataListPage, WorkflowCard,
  WorkshopCard, SectionHeader, SavingsBanner, RailSidebar, MobileTopBar,
  MobileDrawer, RowPreviewDrawer, RowDetailsDialog, StatusBadge, RequireRole.

  Marketing primitives (ported from @tensorcost/component-library, MUI 7-native):
  Hero, FeatureGrid, CTABanner, Testimonials, FAQAccordion, Timeline, LogosStrip,
  StatsCounter, StatsStrip, ImageGallery, VideoEmbed, Comparison, Proof,
  PilotFindings, Guarantee, ContentBlock, TabsSection, MarkdownRichText.

  Charts: opinionated Recharts wrappers themed against tokens.

  — Consumer setup —

  Requires MUI 7 + Emotion + React 18 as peer deps. Consumers must load JetBrains
  Mono themselves (the kit doesn't `@import` fonts on behalf of consumers); see
  @tensorcost/ui-kit README for the recommended `<link>` tag.

  — Compatibility —

  This is a fresh release; no migration notes apply. Future minor and patch
  releases will include changelogs auto-generated by Changesets.
